# 데이터 취득

원본 데이터는 저장소에 포함하지 않는다. 전 기간 합계가 1GB를 넘고 전부 공개
데이터라 각 출처에서 내려받는 편이 낫다.

## 필요한 파일

`HOUSING_DATA_DIR` 로 지정한 폴더에 아래 이름으로 둔다. 인코딩은 CP949다.

| 파일명 | 내용 | 대략 용량 |
|---|---|---:|
| `아파트_전월세.csv` | 아파트 전월세 실거래가 + 시설 파생변수 | 232 MB |
| `연립다세대_전월세.csv` | 연립다세대 전월세 | 138 MB |
| `연립다세대_매매.csv` | 연립다세대 매매 | 48 MB |
| `아파트_매매_전처리.csv` | 아파트 매매 2019Q1 분석셋 | 1 MB |

## 원본 출처

**실거래가** — 국토교통부 실거래가 공개시스템 <https://rt.molit.go.kr>
서울특별시, 2019년 1월부터 2023년 12월까지, 아파트와 연립다세대 각각 매매와
전월세를 받는다. 내려받은 CSV는 상단 15행이 안내문이라 `skiprows=15` 가 필요하다.

**시설 위치** — 서울열린데이터광장 <https://data.seoul.go.kr>
병의원, 약국, 공공도서관, 버스정류소 위치 정보를 받는다.

**대규모점포** — 공공데이터포털 <https://www.data.go.kr> 의 전국 대규모점포 표준데이터.

**좌표 변환과 최근접 시설** — 카카오맵 로컬 API <https://developers.kakao.com>
주소 검색으로 도로명을 위경도로 바꾸고, 키워드 검색으로 학교와 지하철역,
정류소를 찾는다. REST API 키가 필요하며 본인 키를 발급받아 환경변수로 둘 것.

**가격지수** — 한국부동산원 R-ONE <https://www.reb.or.kr/r-one>
시군구별 분기별 아파트 매매 실거래가격지수.

## 파생변수 생성

실거래가에 시설 정보를 붙이는 단계는 이 저장소에 포함하지 않았다. API 키가
필요하고 호출량이 많아 재현 비용이 크기 때문이다. 생성 규칙은 아래와 같다.

- **최근접 거리 5종** 초·중·고등학교, 지하철역, 버스정류소. 반경 5km 안에서
  검색한 뒤 Haversine 직선거리를 계산하고 최솟값을 취한다.
- **반경 개수 7종** 소방서, 경찰서, 대형마트, 공공도서관, 병원은 1.3km 반경.
  편의점과 약국은 300m 반경. 도보 접근이 중요한 두 가지만 좁게 잡아 밀도 지표의
  의미를 보존한다.
- **병합 키** 도로명, 단지명, 위경도.

시계열 파생변수와 공간 파생변수는 `src/prep.py` 가 원본 CSV에서 직접 만든다.
별도 준비가 필요 없다.

## 주의

아파트 매매 병합 파일은 2020년 이후 전용면적이 결측이다. 이 때문에 아파트 매매
분석은 2019년 1분기로 한정했다. 다른 네 유형은 전 구간 결측이 없다.
