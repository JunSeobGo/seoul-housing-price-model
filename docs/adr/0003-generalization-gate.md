# ADR-0003: 결론은 20칸에서 확인한 뒤 채택한다

- 상태 채택
- 날짜 2026-09-12

## 배경

초기 분석은 2019Q1 아파트 매매 한 표본에서 여러 결론을 얻었다. 그중 일부가
다른 거래유형이나 시점으로 넘어가지 않는다는 것을 확인했다.

예를 들어 "인프라 변수 15종이 동별 중앙값 기준선보다 나쁘다"는 결론은 아파트
매매에서는 맞지만 다른 20칸에서는 20칸 전부 반대로 나온다.

## 결정

주요 결론은 **5개 거래유형 × 4개 시점 = 20칸**에서 재확인한 뒤에만 채택한다.
판정 기준은 실험 전에 정하고 결과를 보고 바꾸지 않는다.

판정은 네 등급으로 나눈다.

- **채택** 20칸 전부 또는 명확한 하위집단 전부에서 성립
- **조건부** 15칸 안팎에서 성립하며 성립 조건을 명시할 수 있음
- **축소** 방향은 유지되나 크기가 크게 줄어듦
- **기각** 반대 결과가 다수

## 근거

이 절차를 여덟 개 결론에 적용한 결과다.

| 결론 | 판정 |
|---|---|
| 지하철 거리와 건축년도의 방향 | 채택 |
| 재건축 U자가 매매에만 나타남 | 채택 |
| 역세권 500m 임계 | 조건부 |
| 규모별 U자 | 조건부 |
| 파생변수 8종의 개선폭 | 축소 |
| 병원 방향의 일관성 | 축소 |
| 인프라 변수가 기준선보다 나쁨 | 기각 |
| 편의점이 가격을 낮춤 | 기각 |

채택이 둘, 조건부가 둘, 축소와 기각이 넷이다. 단일 표본 결론을 그대로 쓰면
절반이 틀린다.

## 결과

- 실험 시간이 늘어난다. 한 결론을 확인하는 데 20번 학습이 필요하다.
- 보고서에 "이 조건에서만 성립한다"는 단서가 많아진다. 읽기는 불편해지지만
  그게 사실이다.
- 판정 기준을 미리 정해야 하므로 탐색적 분석과 확인적 분석을 분리하게 된다.

## 대안

통계적 검정을 쓰는 방법이 있다. 20칸의 성능 차이에 부트스트랩 신뢰구간을 붙이면
15 대 5 같은 애매한 경우를 판정할 수 있다. 지금은 개수 세기만 한다. 한계로
기록해 둔다.
