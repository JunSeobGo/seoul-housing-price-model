# ADR-0006: 원본 데이터와 초기 노트북을 저장소에서 제외한다

- 상태 채택
- 날짜 2026-09-12

## 배경

작업 폴더에는 원본 CSV 1.1GB, 탐색용 주피터 노트북, 발표자료, 영상이 함께 있다.
노트북에는 외부 API 키가 하드코딩되어 있다.

## 결정

저장소에는 재현 가능한 코드와 결과물, 문서만 둔다. 구체적으로 제외한다.

- **원본 데이터** 전체. 용량이 크고 전부 공개 데이터다.
- **탐색용 노트북** 전체. 카카오 REST 2종, 구글맵, 공공데이터포털, 금융감독원
  키가 18건 들어 있다.
- **발표자료와 영상.**

대신 `data/README.md` 에 출처와 파생변수 생성 규칙을 문서화한다.

## 근거

- 자격증명이 공개 저장소에 올라가면 회수가 불가능하다. 커밋 이력에 남는다.
- 데이터는 국토교통부와 서울열린데이터광장에서 누구나 받을 수 있다. 저장소에
  둘 이유가 없다.
- 파생변수 생성은 API 호출량이 많아 재현 비용이 크다. 규칙을 문서로 남기는 편이
  실용적이다.

## 결과

- 저장소 크기가 0.3MB 로 유지된다.
- 완전한 재현에는 데이터 준비 단계가 필요하다. `data/README.md` 가 그 간극을
  메운다.
- 실행 경로를 `HOUSING_DATA_DIR` 환경변수로 받아 로컬 절대경로가 코드에 남지
  않게 한다.

## 대안

Git LFS 나 DVC 로 데이터를 버전 관리하는 방법이 있다. 공개 데이터를 다시 올릴
이유가 없고 용량 비용만 생겨 채택하지 않았다.
