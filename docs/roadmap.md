# 후속 작업

보고서 13절의 한계를 실행 단위로 쪼갠 목록이다. 우선순위는 **지금 문서에 적힌
주장을 지키는 일**을 앞에 두고, 새 기능은 뒤에 둔다.

각 항목은 브랜치 이름과 완료 조건을 함께 적는다.

---

## P0 · 기존 주장을 지키는 일

### 1. 20칸 비교에 신뢰구간을 붙인다

`feat/bootstrap-ci`

지금 20칸 판정은 개수 세기다. 20 대 0은 명확하지만 15 대 5는 애매하고 그것을
판정할 도구가 없다.

- [ ] 각 칸의 MAE 차이에 부트스트랩 신뢰구간을 계산한다
- [ ] 20칸을 묶어 효과 크기와 구간을 하나로 요약한다
- [ ] 조건부 판정 두 건(역세권 임계, 규모 U자)을 다시 판정한다

**완료 조건** ADR-0003 의 판정표에 구간이 붙고, 조건부 두 건의 등급이 확정된다.

### 2. 하이퍼파라미터 탐색을 20칸으로 넓힌다

`feat/tuning-all-cells`

탐색과 모델 비교가 2019Q1 아파트 매매 한 칸 기준이다. ADR-0003 의 기준을 이
결론만 통과하지 않았다.

- [ ] 5개 유형 × 4개 시점에 동일 예산 탐색을 적용한다
- [ ] 튜닝 이득 4.2%와 모델 교체 이득 4.1%가 20칸에서 유지되는지 본다
- [ ] 세그먼트별로 최적 파라미터가 얼마나 다른지 정리한다

**완료 조건** 보고서 6-2 레버 표의 마지막 두 행에 20칸 근거가 붙는다.

### 3. 성능 수치를 3단계 검증 기준으로 다시 낸다

`feat/forward-chain-all`

보고서의 성능 수치 대부분이 2단계(단지 그룹, 분기 내) 기준이라 낙관적이다.

- [ ] 5개 유형 전부에 시간 기반 분할을 적용한다
- [ ] 기준선 사다리와 레버 비교를 3단계 기준으로 다시 만든다
- [ ] 2단계와 3단계 수치를 나란히 두어 낙관 정도를 명시한다

**완료 조건** 보고서 5절과 6절의 표가 두 단계를 함께 보여준다.

## P1 · 서비스로 이어지는 일

### 4. 분위 회귀와 예측구간

`feat/quantile-regression`

서비스가 실제로 보여주는 것은 점추정이 아니라 "같은 조건 매물 중 상위 몇
퍼센트"다. 지금은 점추정만 있다.

- [ ] 10 / 50 / 90 분위 모델을 학습한다
- [ ] 80% 구간의 실제 포함률을 측정해 보정 여부를 판단한다
- [ ] 개별 매물의 확률적 위치(PIT)를 계산하고 균등성을 확인한다

**완료 조건** 임의 매물에 대해 적정가 구간과 백분위를 함께 낼 수 있다.

### 5. 종속변수를 상대 단가로 바꿔 본다

`feat/relative-target`

`log(단가) - log(동 직전분기 중앙단가)` 를 종속변수로 두면 수준 정보가 오프셋으로
빠진다. 트리 모델의 외삽 한계와 국면 전환 취약성이 함께 완화될 수 있다.

- [ ] 절대 단가 타깃과 상대 단가 타깃을 시간 기반 분할에서 비교한다
- [ ] 2022Q4~2023Q1 국면 전환 구간에서 특히 차이를 본다

**완료 조건** 11-1절의 2023Q1 -24.3% 악화가 개선되는지 수치로 답한다.

### 6. 앱 반영 제안을 구체화한다

`docs/service-notes`

- [ ] 역세권 표시를 연립다세대는 500m 임계, 아파트 전세는 연속값으로 분기한다
- [ ] 편의점 개수를 생활 편의 지표에서 내린다
- [ ] 월세 세그먼트의 규모 백분위를 환산보증금 기준으로 바꾼다

**완료 조건** 각 제안에 근거 절 번호와 예상 영향이 붙는다.

## P2 · 데이터와 환경

### 7. 아파트 매매 전 구간을 복구한다

`fix/apt-sale-area`

원본 병합 파일에서 2020년 이후 전용면적이 100% 결측이다. 아파트 매매 분석이
2019Q1 한 분기에 묶여 있다.

- [ ] 국토교통부에서 아파트 매매 원본을 다시 받는다
- [ ] 시설 파생변수를 다시 붙인다
- [ ] 20칸 격자를 6개 유형으로 완성한다

**완료 조건** 아파트 매매가 다른 유형과 같은 4시점 분석에 들어간다.

### 8. 거리를 도보 거리로 바꾼다

`feat/walking-distance`

현재 거리는 Haversine 직선거리다. 실제 접근성과 차이가 있고, 특히 강을 사이에
두거나 경사가 있는 구간에서 왜곡이 크다.

- [ ] 경로 탐색 API로 도보 거리를 산출한다
- [ ] 직선거리 대비 역세권 임계가 어떻게 달라지는지 비교한다

**완료 조건** 10-2절의 500m 임계가 도보 기준에서도 성립하는지 답한다.

### 9. LightGBM 비교를 복구한다

`chore/fix-lightgbm`

현재 환경의 설치가 손상되어 200행 5열 난수 행렬에서도 종료된다. 재설치를
시도하면 numpy 의존성이 올라가 다른 패키지가 깨진다.

- [ ] 격리된 가상환경에서 설치한다
- [ ] ADR-0005 의 모델 비교표에 추가한다

**완료 조건** GBM 계열 세 종을 동일 예산으로 비교한 표가 나온다.
