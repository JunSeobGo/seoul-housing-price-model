# 포트폴리오 요약

한 장 분량으로 압축한 버전이다. 전체 분석은 [report.md](report.md) 에 있다.

---

## 한 줄

서울 실거래가 2019~2023년 20개 분기에 생활 인프라·공간·시계열 변수를 붙여
주택 단가 결정요인을 분해하고, **모든 결론을 20개 표본 조합에서 재확인한 뒤에만
채택하는 절차**를 세웠다.

## 맡은 일

데이터 수집 설계, 도로명 좌표 변환과 매물–시설 거리 계산, 파생변수 12종 정의와
생성, 실거래가와 파생변수 병합 키 설계, 모델링과 검증 설계 전반.

## 규모

| 항목 | 값 |
|---|---|
| 분석 기간 | 2019Q1 – 2023Q4, 20개 분기 |
| 거래유형 | 5종 (아파트 전월세, 연립다세대 매매·전월세) |
| 표본 | 아파트 전세 606,652건 외 총 170만건 |
| 파생변수 | 매물당 12종 + 공간 4종 + 단지 4종 + 시계열 6종 |
| 모델 | XGBoost, CatBoost, RandomForest, Ridge |
| 실험 스크립트 | 14종, 전부 독립 실행 가능 |

## 핵심 결과 다섯

### 1. 종속변수를 잘못 두면 분석 전체가 항등식이 된다

거래 총액은 단가와 면적의 곱이다. 면적을 독립변수로 넣고 총액을 맞추면 면적이
1순위로 나오는 게 당연하다. 종속변수를 제곱미터당 단가로 바꾸자 전용면적 중요도가
**0.328에서 0.027로** 떨어지고 건축년도와 입지 변수가 상위로 올라왔다.

총액 기준 R² 0.877 중 대부분이 면적이 만들어준 값이었다.

### 2. 검증 설계가 성능 수치를 두 배 바꾼다

| 분할 | 남은 누수 | 아파트 매매 MAE |
|---|---|---:|
| 무작위 | 단지 중복 + 미래 정보 | 9,708만원 |
| 단지 그룹 | 미래 정보 | 17,713만원 |
| 시간 기반 | 없음 | 다시 +10~50% |

같은 단지의 다른 층 거래를 보고 맞추는 건 예측이 아니다.

### 3. 성능 레버는 튜닝이 아니라 변수다

| 조치 | 오차 개선 |
|---|---:|
| 위치 변수 추가 | 10.6% |
| 파생변수 8종 추가 | 5.9% |
| 하이퍼파라미터 45회 탐색 | 4.2% |
| 모델 교체 | 4.1% |

튜닝 이득 4.2%는 시드 간 표준편차 4.26의 1.6배에 불과하다. 시드 5개 전부에서
개선된 것이 유일하게 확실한 근거다.

### 4. CatBoost의 우위는 최고 성능이 아니라 강건성이다

동일 예산 45회 탐색에서 **최고 성능 차이는 2.7인데 중앙값 차이는 32.3**이다.
CatBoost는 아무 파라미터나 뽑아도 잘 나오고 XGBoost는 잘 뽑아야 한다.

파라미터 선택 분할과 성능 보고 분할을 분리해 선택 편향을 제거했다.

### 5. 모델이 배운 것이 도메인과 맞는다

재건축 연한 30년을 넘긴 1980년대 초 단지가 1990년대 단지보다 비싸고, 그 U자는
**매매에서만** 나타난다. 매매 5칸 전부, 전월세 16칸 중 0칸이다. 재건축 기대는
소유권 가치에 붙지 거주 비용에는 붙지 않는다.

역세권 프리미엄은 500미터에서 끊긴다. 100미터와 500미터 차이는 63만원인데
500미터에서 1,000미터 사이에 343만원이 빠진다. 도보 7분이라는 시장 기준과 맞는다.

공간 변수에서 **강남역까지 거리가 시청까지 거리보다 4배 이상 중요하다.**

## 가장 내세울 것 — 결론을 채택하기 전에 거르는 절차

단일 표본에서 얻은 결론은 자주 무너진다. 주요 결론 여덟 건을 5개 거래유형 ×
4개 시점 = 20칸에서 재확인했다.

| 결론 | 판정 |
|---|---|
| 지하철 거리와 건축년도의 방향 | 채택 (20/20, 두 방법 일치) |
| 재건축 U자가 매매에만 나타남 | 채택 (매매 5/5, 전월세 0/16) |
| 역세권 500m 임계 | 조건부 (15/20, 연립다세대에서 강함) |
| 규모별 U자 | 조건부 (15/20, 아파트 월세 0/4) |
| 파생변수 개선폭 16.3% | 축소 (20칸 평균 5.9%) |
| 병원 방향의 일관성 | 축소 (연립 매매 3칸 음수) |
| 인프라 변수가 기준선보다 나쁨 | 기각 (20/20 반대) |
| 편의점이 가격을 낮춤 | 기각 (효과 ±10% 안쪽) |

**채택 둘, 조건부 둘, 축소와 기각 넷.** 절반이 단일 표본에서만 성립했다.

이 비율이 이 프로젝트에서 가장 중요한 숫자다. 절차 하나가 여덟 개 결론 중
네 개를 걸러냈다.

## 기술적으로 짚은 것들

**변수 중요도는 계산 방식에 따라 0.05에서 0.51까지 벌어진다.** `gain` 과
`total_gain` 이 다르고, 트리 깊이를 10으로 하면 1순위 변수 자체가 바뀐다.
시점 간 중요도 비교는 모든 설정을 고정했을 때만 유효하다.

**방향을 상관계수 하나로 요약하면 곡선이 뭉개진다.** 지하철역까지 거리는 부호가
20칸 전부 음수인데 단조는 9칸뿐이고 역U자가 9칸이다. 그 비단조성이 바로 500미터
임계다. 부분의존도로 바꿔 효과 크기와 형태까지 산출했다.

**시계열 변수는 평시에 벌고 국면 전환에서 잃는다.** 직전 분기 단가를 넣으면 평균
4% 개선되지만 2023Q1에는 **-24.3%**다. 금리 급등과 전세 시장 경색이 겹친 구간에서
직전 가격이 정확히 반대 신호를 준다. 두 세그먼트가 같은 시기에 같은 방향으로
실패했다.

**구조 전환 시점은 가격지수 최고·최저와 다르다.** 아파트 전세의 1순위 변수가
16분기 내내 구 더미였다가 2023년 네 분기에서 전용면적으로 바뀐다. 가격 수준이
움직인 시점과 모델 구조가 바뀐 시점이 달랐다.
