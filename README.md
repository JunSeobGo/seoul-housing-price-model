# 서울 주택 단가 결정요인 분석

국토교통부 실거래가에 생활 인프라·공간·시계열 변수를 붙여, **"이 매물이 주변
대비 비싼가"** 에 답하는 모델을 만들고 무엇이 단가를 만드는지 분해한다.

- 기간 2019Q1 – 2023Q4 (20개 분기)
- 지역 서울 25개 구
- 유형 아파트 전세·월세, 연립다세대 매매·전세·월세
- 모델 XGBoost, CatBoost, RandomForest, Ridge

---

## 핵심 결과 다섯 가지

**1. 종속변수를 거래 총액으로 두면 분석이 무의미해진다.**
거래 총액은 단가와 면적의 곱이다. 면적이 종속변수 안에 곱셈으로 들어 있어
트리 모델이 면적을 1순위로 잡는 건 발견이 아니라 항등식이다. 종속변수를
제곱미터당 단가로 바꾸면 전용면적 중요도가 **0.328에서 0.027로** 무너지고
입지 변수가 비로소 경쟁한다.

**2. 검증 설계가 성능 수치를 두 배 이상 바꾼다.**

| 분할 방식 | 남아 있는 누수 | 아파트 매매 MAE |
|---|---|---:|
| 무작위 | 같은 단지 + 미래 정보 | 9,708 |
| 단지 그룹, 분기 내 | 미래 정보 | 17,713 |
| 시간 기반 | 없음 | 다시 +10~50% |

같은 단지의 다른 거래가 학습과 평가에 동시에 들어가면 성능이 부풀려진다.

**3. 성능을 올리는 건 튜닝이 아니라 변수다.** 20칸 평균 기준.

| 조치 | 오차 개선 |
|---|---:|
| 위치 변수 추가 | 10.6% |
| 파생변수 8종 추가 | 5.9% |
| 하이퍼파라미터 45회 탐색 | 4.2% |
| 모델 교체 (XGB → CatBoost) | 4.1% |

**4. CatBoost의 우위는 최고 성능이 아니라 강건성이다.**
동일 예산 45회 탐색에서 최고 성능 차이는 2.7인데 중앙값 차이는 32.3이다.
CatBoost는 아무 파라미터나 뽑아도 잘 나오고 XGBoost는 잘 뽑아야 한다.

**5. 모델이 배운 것이 부동산 도메인과 맞는다.**
재건축 연한 30년을 넘긴 1980년대 초 단지의 가격이 1990년대 단지보다 높고,
그 U자는 **매매에서만** 나타난다 (매매 5/5, 전월세 0/16). 재건축 기대는
소유권 가치에 붙지 거주 비용에는 붙지 않는다는 뜻이다.

## 방법론 — 결론을 채택하기 전에 20칸에서 확인한다

단일 표본에서 얻은 결론은 자주 일반화되지 않는다. 이 프로젝트는 모든 주요
결론을 **5개 거래유형 × 4개 시점 = 20칸**에서 재확인한 뒤에만 채택했다.

그 절차가 걸러낸 것들이다.

| 한 칸에서 보인 것 | 20칸 결과 |
|---|---|
| 인프라 변수가 동별 중앙값보다 나쁨 | 20/20에서 반대. 아파트 매매만의 특수 사례 |
| 편의점이 가격을 낮춤 | 음 11 / 양 9로 갈림. 효과 크기도 10% 안쪽 |
| 파생변수가 16.3% 개선 | 20칸 평균 5.9% |
| 병원 방향이 일관 양 | 연립 매매 3칸에서 음수 |
| 역세권 500m 임계 | 15/20. 연립다세대에서만 강함 |
| 규모별 U자 | 15/20. 아파트 월세는 0/4 |

20칸 전부에서 방향이 일관된 변수는 **지하철역까지 거리와 건축년도 둘뿐**이다.

## 구조

```
src/
  config.py                 경로 설정 (환경변수)
  prep.py                   데이터 파이프라인 · 피처 계보 정의
  experiments/
    01_target_and_validation.py     종속변수 교체, 검증 분할 비교
    02_baseline_ladder.py           기준선 사다리, 위치 변수
    03_shap_direction.py            SHAP 방향성
    04_segment_performance.py       6개 세그먼트 성능
    05_importance_sensitivity.py    중요도 민감도, 탐색 45회
    06_partial_dependence.py        부분의존도, 도메인 대조
    07_all_segments_quarters.py     4시점 × 5유형
    08_generalization_check.py      핵심 주장 20칸 확인
    09_seed_variance_and_models.py  시드 분산, 파생변수, 모델 비교
    10_catboost_eval.py             CatBoost 단독 평가
    11_fair_model_comparison.py     동일 예산 공정 비교
    12_generalization_round2.py     2차 20칸 확인
    13_pdp_direction.py             방향 산출을 부분의존도로
    14_time_series.py               시간 분할 · lag 변수 · 20분기 추이
results/                    각 실험의 원본 출력
docs/report.md              전체 분석 문서
data/README.md              데이터 취득 방법
```

## 실행

```bash
pip install -r requirements.txt
export HOUSING_DATA_DIR=/path/to/data      # Windows: set HOUSING_DATA_DIR=...
python src/experiments/01_target_and_validation.py
```

데이터는 저장소에 포함하지 않는다. 용량이 1GB를 넘고 전부 공개 데이터다.
취득 방법은 [data/README.md](data/README.md) 를 볼 것.

## 환경

Python 3.11 · XGBoost 2.0.3 · CatBoost 1.2.10 · scikit-learn 1.6.1 · shap 0.46

LightGBM은 이 환경의 설치가 손상되어 비교에서 제외했다. 200행 5열 난수
행렬에서도 메모리 접근 위반으로 종료된다.
